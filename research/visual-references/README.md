# 公开效果参考库

这里保存公开页面的索引与独立实现选题，供日后自行编写开源实现。它与主资源目录及网站模板清单分开，不代表原项目开源、可下载源码或允许复制素材。

仅保存公开链接和我们自己编写的设计问题；不保存个人下载包、账户信息、受保护源码、解锁缓存或第三方视频副本。效果预览优先在原作者公开页面观看。此处的“实现选题”是待验证的独立设计方向，不是对原包内部实现的描述。

建议每次选择一个效果，记录公开页面中观察到的构图、节奏与转场，再从空项目编写自己的实现，使用自制或明确允许复用的素材。将参考链接、观察笔记和实现方案分开；新实现通过源码、许可及实际渲染检查后，才考虑加入主目录。
